=== Firebase Storage PDF ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: ISC

Displays programme PDFs from Firestore using a Lit web component.

== Usage ==

Configure the plugin under Settings > Firebase Storage PDF, then add:

[firebase_programme_pdf programme="technical" width="600px" height="849px"]

Add continuous="yes" to show all pages in one scrollable column without paging controls.
